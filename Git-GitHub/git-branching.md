# 🌿 Git Branching

> Basic notes about branches and how they are used in Git workflows.

## What is a Branch?

A branch is an independent line of development in a Git repository.

Branches allow developers to work on new features, fixes, or experiments without directly changing the main version of the project.

A simple example:

```text
main
 │
 ├── feature-login
 │
 └── bugfix-navbar
